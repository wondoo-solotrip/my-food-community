# UI Components

파운데이션(토큰 · 컬러 · 타이포그래피 · 아이코노그래피) 위에 올라가는 UI 컴포넌트 핸드오프입니다. `design.pen`에 등록된 reusable 컴포넌트를 전부 코드로 옮겼습니다.

## 변환 규칙

`.pen`은 **변형 하나당 컴포넌트 하나**입니다. `Button`은 27개, `Text Field`는 24개가 각각 독립 컴포넌트로 등록되어 있습니다. 캔버스에서는 이 방식이 옳습니다 — 모든 조합을 한눈에 늘어놓고 검토할 수 있으니까요.

코드에서는 그럴 수 없습니다. 27개 컴포넌트를 그대로 옮기면 호출부가 조합을 직접 골라야 하고, 토큰이 바뀔 때 27곳을 고쳐야 합니다. 그래서 **변형 축을 props로 접습니다.**

```tsx
// .pen: Button / PRIMARY / LOADING / MD  →  코드
<Button variant="primary" size="md" loading>계속하기</Button>

// .pen: Text Field / PASSWORD / ERROR / LG  →  코드
<TextField type="password" size="lg" state="error" label="비밀번호" … />
```

축을 props로 옮기는 기준은 세 가지입니다.

## 토큰 사용

컴포넌트는 **시맨틱 토큰과 `type-*` 유틸리티만** 사용합니다. 프리미티브 참조나 hex 직접 입력은 없습니다.

```tsx
// ✅ 시맨틱 토큰 유틸리티
'bg-background-brand text-text-on-brand border-border-strong'

// ✅ 타이포그래피 유틸리티
'type-label-lg'
```

변형별 클래스는 룩업 테이블에 리터럴로 적어 둡니다. `` `text-text-${tone}` `` 같은 계산된 클래스명은 Tailwind의 정적 스캐너가 볼 수 없어 CSS가 생성되지 않습니다.

```tsx
const VARIANT: Record<ButtonVariant, string> = {
  primary: 'bg-background-brand text-text-on-brand border-transparent',
  secondary: 'bg-background-surface text-text-default border-border-strong',
  destructive: 'bg-background-surface text-text-error border-border-error',
};
```

`cn()`은 truthy한 클래스만 이어 붙이는 12줄짜리 함수입니다. `tailwind-merge`를 넣지 않은 이유는, 위 구조에서 같은 CSS 속성을 다투는 유틸리티가 한 문자열에 함께 들어가지 않기 때문입니다.

### 공유 상태 맵

`Text Field` · `Textarea` · `Select`는 `.pen`에서 서로 다른 계열이지만, 네 상태가 정확히 같은 토큰으로 해석됩니다. <C>field.ts</C>에 한 벌만 두고 세 컴포넌트가 함께 읽습니다 — 토큰이 바뀌면 세 곳에 동시에 반영되고, 나중에 셋이 달라져야 한다면 그 사실이 명시적으로 드러납니다.

## 검토 결과

가이드 08 ~ 13의 최종 검토사항을 코드 기준으로 확인했습니다.

- [x] **프레임 → 컴포넌트** — `.pen`의 UI 컴포넌트 170개가 모두 코드 컴포넌트로 매핑됨 (위 인덱스의 개수 합계와 일치)
- [x] **소스** — 컬러는 시맨틱 토큰, 텍스트는 `type-*` 유틸리티, 아이콘은 아이코노그래피 파운데이션의 `<Icon>`, 버튼·아이콘버튼은 기존 컴포넌트를 재사용
- [x] **정렬** — 모든 `AllVariants` 스토리가 타입(행) × 상태(열) 매트릭스
- [x] **색상** — subtle 계열은 명시된 곳(`background-image-placeholder-warm`)에서만 사용. 원시 hex 2건은 시맨틱 토큰으로 대체하고 위 표에 기록
- [x] **개별조건** — 사이즈·아이콘 크기·패딩·간격을 `.pen` 실측값으로 재현. 예외 1건(Button sm 패딩)은 위 표에 기록
- [x] **아이콘버튼 수정 금지** — 배경 3종 그대로. 상태를 추가하지 않음
- [x] **회귀 가드** — `Components/Tests`가 지오메트리와 시맨틱 토큰 해석을 브라우저에서 검증
