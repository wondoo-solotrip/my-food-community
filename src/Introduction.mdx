## 구조

- Foundation and component specs live in the `*-ds-*.txt` files at the project root.
- Stories are colocated with their components as `*.stories.tsx`.
- Global styles come from `src/app/globals.css`, imported once in `.storybook/preview.tsx`.
- `src/foundation/*.ts` — token data and usage notes for the catalog. Never redefines a colour value.
- `src/foundation/docs/` — catalog MDX pages and their documentation-only renderers.
- `src/foundation/icons.ts` — SVG paths generated from `design.pen`. Do not edit by hand.
- `src/components/` — UI components, one file per `.pen` family, plus `index.ts` as the public surface.
- `src/components/docs/` — the overview page, its handoff ledger (`inventory.ts`), and the regression guards.
