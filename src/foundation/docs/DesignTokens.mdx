# Design Tokens

`design.pen`의 `variables`를 코드로 옮긴 결과입니다. 디자인 파일의 토큰 이름을 그대로 유지해 디자이너와 개발자가 같은 어휘를 씁니다.

## 핸드오프 경로

```
design.pen (variables)
  └─ Pencil MCP get_variables ─→ src/app/globals.css        토큰 정의 (CSS 변수 + Tailwind @theme)
                                 src/foundation/*.ts        문서용 토큰 데이터 + 용도 설명
design.pen (Icon / * 컴포넌트)
  └─ Pencil MCP export_html ───→ src/foundation/icons.ts     36종 SVG path (자동 생성)
```

정의는 `globals.css` 한 곳에만 있습니다. `src/foundation/*.ts`는 카탈로그 렌더링과 용도 설명을 위한 메타데이터이며, 색상값을 **다시 정의하지 않고** 스와치를 `var(--color-…)`로 칠합니다. 두 레이어가 어긋나면 카탈로그 화면에서 바로 드러납니다.

## 사용 방법

컬러 토큰은 Tailwind `@theme`에 등록되어 있어 유틸리티와 CSS 변수 양쪽으로 접근할 수 있습니다.

```tsx
// Tailwind 유틸리티 — 대부분의 경우 이걸 쓰세요
<article className="bg-background-surface border border-border-default text-text-body">
  <h3 className="type-heading-sm text-text-default">우리 동네 푸드 커뮤니티</h3>
  <p className="type-body-md">제철 재료와 다정한 레시피가 매일의 식탁을 채웁니다.</p>
</article>
```

```css
/* CSS 변수 — 유틸리티로 표현이 안 되는 곳 (그라디언트, box-shadow 등) */
.fab {
  box-shadow: 0 8px 24px var(--color-shadow-action);
  background: var(--color-background-brand);
}
```

타이포그래피·스페이싱 프리미티브는 `var(--font-size-300)`, `var(--spacing-16)` 형태로만 참조합니다. 이유는 아래 네임스페이스 항목을 보세요.

## 스페이싱

<SpacingScale />

디자인 시스템의 6단계가 Tailwind 기본 스케일(`--spacing` × n)과 **정확히 1:1로 대응**합니다. 별도 유틸리티를 만들지 않고 Tailwind 기본값을 그대로 쓰면 됩니다.

`spacing-20`은 가이드에 용도가 기재되어 있지 않습니다. 실제 사용처가 정해지면 문서를 갱신해야 합니다.

## Tailwind v4 네임스페이스 주의사항

디자인 파일의 토큰 이름을 그대로 `@theme`에 넣을 수 있는지는 토큰 종류마다 다릅니다.

        <C>@theme</C>에 넣으면 <C>{'.font-size-300 { font-family: 16px }'}</C> 같은 무의미한

      </span>,
    ],
    [
      <C>spacing-*</C>,
      <C>:root</C>,
      <span>
        <C>@theme</C>의 <C>--spacing-*</C>에 넣으면 <C>p-8</C>이 32px에서{' '}
        <strong>8px로 바뀜</strong>. Tailwind 기본 스케일을 조용히 망가뜨리는 함정
      </span>,
    ],
  ]}
/>

`@theme`가 아니라 `@theme static`을 쓴 이유: Tailwind는 기본적으로 사용되지 않는 토큰 변수를 출력에서 제거합니다. 카탈로그는 스와치를 `var(--color-…)`로 칠하는데 이는 정적 스캐너에 잡히지 않으므로, `static`으로 전체 토큰을 강제 출력합니다. 디자인 시스템의 토큰 레이어는 사용 여부와 무관하게 전부 존재해야 한다는 점에서도 맞는 선택입니다.

합성 타입 스타일은 `@utility`로 등록해 `type-display-lg` 같은 클래스 하나로 크기·두께·행간·자간이 함께 적용되도록 했습니다.

## 다크 모드

`design.pen`은 단일 라이트 테마만 정의합니다. 따라서 `prefers-color-scheme` 오버라이드를 넣지 않았습니다 — 토큰 세트 밖의 색상으로 떨어지기 때문입니다. 다크 모드가 필요해지면 디자인 파일에 테마를 추가한 뒤 시맨틱 계층의 참조만 바꾸면 됩니다. 프리미티브와 컴포넌트는 그대로 둘 수 있습니다. 이것이 2계층 구조를 유지하는 실질적인 이유입니다.

## 동기화

디자인 파일이 바뀌면:

1. **컬러·타이포·스페이싱** — Pencil MCP `get_variables`로 값을 확인하고 `globals.css`와 해당 `src/foundation/*.ts`를 함께 수정합니다.
2. **아이콘** — `Icon / * / 24` 노드를 `export_html`로 내보내 `icons.ts`를 재생성합니다. 이 파일은 자동 생성물이므로 직접 편집하지 마세요.
