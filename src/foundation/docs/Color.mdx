# Color

`design.pen`의 컬러 변수를 그대로 옮긴 2계층 토큰 체계입니다.

컴포넌트와 화면에서는 **시맨틱 토큰만 사용합니다.** 프리미티브를 직접 참조하면 의미가 사라지고, 이후 색상 교체 시 일괄 변경이 불가능해집니다. hex 직접 입력은 어느 계층에서도 허용하지 않습니다.

```tsx
// ✅ 시맨틱 토큰
<p className="text-text-secondary bg-background-surface">…</p>

// ⚠️ 프리미티브 직접 사용 — 의미가 드러나지 않음
<p className="text-neutral-600">…</p>

// ❌ hex 직접 입력
<p style={{ color: '#5f5751' }}>…</p>
```

Tailwind v4 `@theme`에 등록되어 있으므로 모든 토큰은 유틸리티로도 쓸 수 있고, `var(--color-…)`로도 참조할 수 있습니다.

## 프리미티브 팔레트

6개 계열, 각 `50`–`950`의 11단계입니다. 아래 스와치는 CSS 변수(`var(--color-…)`)로 직접 칠해지고, 캡션의 hex는 토큰 데이터에서 출력됩니다 — 두 값이 어긋나면 이 페이지에서 바로 드러납니다.

<PrimitivePalette />

<div style={{
  padding: '12px 16px',
  borderRadius: 8,
  background: 'var(--color-background-information)',
  border: '1px solid var(--color-border-information)',
  fontSize: 13,
}}>
  <strong>가이드와의 차이 1건</strong> — 뉴트럴 계열은 11단계가 아니라 <strong>12단계</strong>입니다.
  카드·시트 표면(<code>color-background-surface</code>)에 쓰이는 순백(<code>#ffffff</code>)이
  <code>color-neutral-0</code>으로 추가되어 있습니다. <code>neutral-50</code>은 페이지 배경용
  웜 화이트(<code>#fffdf9</code>)라 순백과 역할이 다릅니다.
</div>

### 알파 프리미티브

오버레이와 그림자 전용 반투명 색상입니다. 50–950 램프가 아니라 불투명도 기준으로 이름이 붙습니다. 체커보드 위에 렌더해 투명도를 확인할 수 있게 했습니다.

## 접근성 — 배경 대비

가이드 요건: *각 팔레트별 뉴트럴색(`neutral-50`) 대비 3:1, 4.5:1을 만족하는 컬러 선택이 가능해야 함.*

기준면은 페이지 기본 배경인 `color-neutral-50`(`#fffdf9`)이며, 비율은 WCAG 2.1 상대휘도 공식으로 계산했습니다.

- **3:1** — 큰 텍스트(24px 이상 또는 19px 이상 볼드), 아이콘, 테두리 등 비텍스트 요소 (§1.4.11)
- **4.5:1** — 일반 크기 본문 텍스트 (§1.4.3)

<ContrastSummary />

6개 계열 모두 3:1과 4.5:1을 만족하는 단계를 보유하므로 요건은 충족됩니다. 계열별 전체 수치는 아래와 같습니다.

## 시맨틱 토큰

### Text

대비는 각 토큰이 **놓이도록 설계된 배경** 기준으로 측정합니다. `color-text-on-brand`를 밝은 페이지 배경에 대고 재면 의미가 없으므로, 브랜드 배경(`color-brand-700`) 기준으로 계산했습니다. 측정 기준은 각 행에 표기됩니다.

`color-text-disabled`는 의도적으로 낮은 대비를 갖습니다. WCAG 2.1 §1.4.3은 비활성 컨트롤을 대비 요건에서 제외하므로 **예외**로 표시했습니다.
