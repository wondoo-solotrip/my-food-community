# Iconography

[Lucide](https://lucide.dev) 기반 **36종**의 아이콘을 **16 · 20 · 24 · 32px** 네 가지 크기로 제공합니다. `design.pen`에는 조합별로 컴포넌트가 하나씩, 총 **144개**(36 × 4)가 등록되어 있습니다.

코드로는 아이콘당 path 하나만 넘어옵니다. 네 크기가 동일한 `14 × 14` 좌표계를 공유하기 때문에, **36개 path가 144개 컴포넌트를 모두 커버**합니다.

## 색상

path가 `currentColor`로 채워지므로 아이콘은 **부모의 텍스트 색을 그대로 상속**합니다. 아이콘 전용 색상 토큰은 따로 두지 않고 `color-text-*` 시맨틱 토큰을 그대로 씁니다.

<IconColorDemo />

```tsx
{/* 부모의 text 색상을 상속 */}
<span className="text-text-error">
  <Icon name="error" size={20} />
</span>
```

`.pen`에서도 모든 아이콘의 `fill`이 `$color-text-default`로 지정되어 있어, 동일한 상속 모델을 따릅니다.

## 이름 매핑

Lucide 원본 이름 대신 역할이 드러나는 이름을 씁니다. 36종 중 **15종**이 리네임되었습니다. Lucide 문서를 참고할 때는 오른쪽 열의 원본 이름으로 검색하세요.

<IconRenameTable />

나머지 21종(`arrow-*`, `chevron-*`, `calendar`, `copy`, `menu`, `search`, `plus`, `bookmark`, `check`, `info`, `user`, `settings`, `heart`, `star`, `image`)은 Lucide 이름과 동일합니다.

## 구현 노트

**아웃라인으로 변환된 path입니다.** Lucide 원본은 `stroke` 기반이지만, `.pen`에서 내보낸 형태는 윤곽선이 채움(fill) path로 변환된 상태입니다. 렌더 결과는 동일하고 크기 변화에도 비율이 유지되지만, **런타임에 `stroke-width`를 바꿀 수는 없습니다.** 디자인 파일과 100% 일치하는 대신 두께 조절 가능성을 포기한 트레이드오프입니다.

**의존성이 없습니다.** `lucide-react`를 설치하지 않고 path를 `src/foundation/icons.ts`에 인라인했습니다. 번들에 36개 path(약 64KB, gzip 후 크게 감소)가 포함되며, 외부 패키지 버전 업데이트로 아이콘 모양이 바뀌는 일이 없습니다.

**접근성.** 카탈로그 렌더러는 `title`이 없으면 `aria-hidden`으로 장식 요소 처리하고, `title`이 주어지면 `role="img"`에 라벨을 붙입니다. 아이콘만으로 동작을 표현하는 버튼에는 반드시 접근 가능한 이름을 부여하세요.

**재생성.** `icons.ts`는 자동 생성 파일입니다. 디자인 파일이 바뀌면 Pencil MCP `export_html`로 `Icon / * / 24` 노드를 내보낸 뒤 다시 파싱해 갱신합니다. 직접 편집하지 마세요.

이 페이지의 `<Icon>`은 카탈로그 렌더링용 도우미이며, 제품 코드용 공용 컴포넌트는 UI 컴포넌트 단계에서 별도로 만듭니다.
